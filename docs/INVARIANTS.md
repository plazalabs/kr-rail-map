## 기준선 운영
1. 처음 설치하면 `node .claude/hooks/stop-check.mjs --update-baseline` 을 한 번 실행한다. 현재 실패 13개가 기준선이 된다.
2. 이후 Claude 가 일을 마칠 때마다 Stop 훅이 돌아간다. 기준선에 없던 실패가 생기면 Claude 는 멈추지 못하고 그것부터 고친다.
3. 실패를 고쳐 줄였으면 **사람이** 기준선을 다시 갱신한다. (Claude 는 이 파일을 고칠 수 없게 막아 두었다)
