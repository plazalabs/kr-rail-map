# PRODUCT.md · 한 쪽짜리 범위 문서 (초안, 직접 고쳐 쓰세요)

> 이 문서에 없는 기능은 만들지 않는다. 피드백이 와도 여기 범위 밖이면 "다음 버전"으로 보낸다.

## 한 줄 정의
역(또는 동네)을 넣으면 **지금 → 개통 후** 업무지구 통근 시간, 그 차이를 만든 **노선**, 그 동네 **시세**를 한 화면에 보여 준다.

## 핵심 흐름 (이것만 완벽하면 된다)
1. 동네·역 입력 (역 이름, 동 이름, 아파트 이름 중 아무거나)
2. 결과 카드: "강남까지 지금 49분 → 2027년 동북선 개통 후 38분 (−11분)" + 법정동 평당가 + 근거(데이터 기준일, 구상/공사 등급)
3. 공유: 카드 이미지 1장, 링크 1개

## 대상 사용자
- 이사·매수를 고민하는 수도권 직장인
- 자기 동네 개통 효과가 궁금한 지역 주민

## 성공 지표 (한 달)
- 첫 방문자 중 결과 카드까지 간 비율
- 공유 카드 생성 수
- 숫자 오류 신고 처리 시간

## 만들 것 (우선순위 순)
1. 숫자 신뢰: 단일 데이터 원천, 법정동 매칭, 시나리오 라벨
2. 첫 3분: 시세 기본 노출, 동 이름 검색, 근거 노선 표시
3. 미래 노선: 공사 중 노선 추가, 구상안 기본 꺼짐 + 등급 배지
4. 개통 랭킹 · 타일 지도 · 통근권 (이미 있음, 숫자만 맞춘다)

## 안 만들 것 (이번 버전)
- 실시간 도착, 역별 시간표, 첫차·막차 → 외부 링크로 대신한다
- 게시판 확장, 그리기·측정 도구 추가
- 새 분석 패널 추가 (지금 있는 것부터 숫자를 맞춘다)
- 테마·노선도 디자인 개편

## 원칙
- "집값 예측 아님"을 지킨다. 구상안 노선으로 만든 순위·추천에는 반드시 등급 배지를 붙인다.
- 숫자 하나를 고치면 그 숫자가 나오는 모든 화면이 같이 바뀌어야 한다.

## 다음 버전: GTX 입구 (gtx.html) — 2026-11-21 회장 결정
- 핵심 흐름은 위와 같다: 역·동 입력 → 카드 1장 → 공유
- 카드: 업무지구 분(지금 → 개통 후) + 접근성 말 + 시세 라벨
- 접근성 순위와 시세는 서로 다른 지표로 따로 표시한다. 둘을 한 점수로 합치지 않는다
- 투표·게시판·실시간 순위는 이 버전에도 넣지 않는다
