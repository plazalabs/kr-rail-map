## 주의 (Known issues)

- **`kric.json`의 한글(이름·설명)은 수집할 때 이미 깨져 있다** (인코딩을 잘못 읽음). 엔드포인트 이름(`convenientInfo/stPlf` 등)과 숫자는 멀쩡하다. 한글이 필요하면 다시 수집해야 한다.
- **`det.json`만 상세 페이지를 확인한 자료다.** 나머지는 목록(제목·기관·요약)뿐이라 무료 여부·호출 한도는 모른다.
- 서울시·KRIC 항목은 목록까지만 확인했다. 무료 여부·호출 한도는 다음 조사 과제다 (`인계_20261109.md` 참고).
- 수집 스크립트는 남아 있지 않다 (대화 중 한 번 쓰고 버림). 다시 모을 때는 위 형식에 맞춰 새로 만든다.
- 뺀 것: 접속 쿠키 파일 2개(`cj`·`sj`, 세션 값이 들어 있음), 긁은 웹페이지 원문 HTML 13개(목록이 아니라 화면 원문), 빈 파일 2개. 인증키는 어느 파일에도 없음을 확인했다.
