## 정해 둔 것
- 70: 상한은 '최적'(화면 '최적' 탭에 나오는 길) 기준 + 20분. 최적보다 같거나 비싼 길만 남으면 최소요금 탭 = 최적 길, 안내 '최적과 같음'. 최적 길이 최소요금 후보를 이겨 바뀌는 규칙(E-11, 숙제 11)은 그대로 — 최적을 먼저 정하고 상한을 건다.
- 70: 후보 탐색을 새로 늘리지 않는다(지금 후보: 거리 최단 길·순수 전철 길·최적·최소환승). 상한 안에 더 싼 길을 찾는 새 탐색은 하지 않음 — 필요하면 회장님 질문.
- 66: 숙제 24(구상 노선 기본 끔)와 겹치는 곳(구상 노선을 켜고 끄는 버튼·배지)은 고치지 않고 목록만 RUN-LOG 에.
