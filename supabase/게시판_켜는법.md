# 게시판 켜는 법 — Supabase 처음 하시는 분용 (약 10분)

게시판 화면(`board.html`)은 다 만들어 두었습니다. 지금은 '준비 중'으로 보입니다.
아래를 차례로 하시고, **7번의 두 값만** 저에게 주시면 제가 넣고 시험한 뒤 올립니다 (약 30분).

1. 크롬에서 **supabase.com** → 오른쪽 위 초록 버튼 **Start your project**
2. **Continue with GitHub** → 사이트 올리는 그 GitHub 계정으로 로그인 → **Authorize(허락)**
3. 처음이면 '조직(Organization)' 이름을 묻습니다 → 아무 이름(예: `plazalabs`) · 요금제 **Free(무료)** → 만들기
4. **New project**
   - Project name: `kr-rail-map`
   - Database Password: **Generate a password** 누르고 **어딘가 적어 두기** (저에게 주지 마세요)
   - Region: **Northeast Asia (Seoul)**
   - **Create new project** → 1~2분 기다리면 초록 화면
5. 왼쪽 세로 메뉴 **SQL Editor** (`>_` 모양) → **+ New query** → 글 쓰는 칸이 나옵니다
6. 이 폴더의 **`board.sql` 내용을 전부 복사**해 그 칸에 붙여 넣고 오른쪽 아래 **Run**
   - "Success. No rows returned" 가 나오면 성공
   - 빨간 글씨가 나오면 그 글씨를 그대로 저에게 보여 주세요
7. 왼쪽 맨 아래 **톱니바퀴(Project Settings)** → **API** (또는 **Data API**)
   - **Project URL** — `https://영문숫자.supabase.co`
   - **anon public** 키 — `eyJ` 로 시작하는 아주 긴 글자 (옆 복사 버튼)
   - ⚠️ 같은 화면의 **service_role (secret)** 키는 **절대 주지 마세요** — 그 키가 있으면 누구나 게시판 전체를 지울 수 있습니다
8. 두 값을 대화창에 붙여 넣기 → 끝

## 글 지우기 (관리)
Supabase → 왼쪽 **Table Editor** → **board_posts** → 지울 글의 줄 왼쪽 네모 체크 → **Delete**.
신고가 3번 쌓인 글은 자동으로 숨겨집니다 (`hidden` 이 true).

## 막아 둔 것
- 글 2~1,000자, 닉네임 20자, 링크 2개까지
- 같은 내용 10분 안 / 한 사람이 1분에 3개 넘게 → DB 가 거절
- 같은 브라우저 20초 안에 연달아 → 화면에서 막음
- 사람 눈에 안 보이는 칸(자동 등록기 잡기)
- 글은 글자로만 보여 줌 (HTML·스크립트 실행 안 됨)
- 공개 키(anon)로는 읽기·글쓰기·신고만 됨 — 고치기·지우기 안 됨 (DB 의 행 수준 보안)
