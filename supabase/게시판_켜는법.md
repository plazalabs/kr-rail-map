# 게시판 켜는 법 (약 10분)

게시판 화면(`board.html`)은 다 만들어 두었습니다. 지금은 '준비 중'으로 보입니다.
아래 순서대로 하시고, **2번에서 나온 두 값만** 저에게 주시면 제가 넣고 올립니다.

## 1. Supabase 가입·프로젝트 만들기
1. https://supabase.com 에서 **Start your project** → GitHub 계정으로 가입
2. **New project** → 이름 `kr-rail-map` · 지역 **Northeast Asia (Seoul)** · 데이터베이스 비밀번호는 아무거나 길게 (저에게 주지 마세요)
3. 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase/board.sql` 내용을 통째로 붙여 넣고 **Run**
   - "Success. No rows returned" 가 나오면 끝

## 2. 저에게 줄 값 두 개
왼쪽 아래 **Project Settings → API**
- **Project URL** — `https://xxxxxxxx.supabase.co`
- **anon public** 키 — `eyJ…` 로 시작하는 긴 글자

⚠️ **service_role** 키와 데이터베이스 비밀번호는 절대 주지 마세요. 사이트에 넣으면 누구나 볼 수 있어서 위험합니다.
anon 키는 공개돼도 괜찮게 만들어 두었습니다 (읽기·글쓰기·신고만 됨, 고치기·지우기 안 됨).

## 3. 커피 한잔 (선택)
- 토스: 토스 앱 → 전체 → **토스아이디** 만들기 → `https://toss.me/아이디`
- 카카오페이: 카카오톡 → 더보기 → 페이 → **송금코드** → 링크 복사

## 관리 (글 지우기)
Supabase → **Table Editor → board_posts** 에서 지울 글의 줄을 지우면 됩니다.
신고가 3번 쌓인 글은 자동으로 숨겨집니다 (`hidden` 이 true).

## 막아 둔 것
- 글 2~1,000자, 닉네임 20자, 링크 2개까지
- 같은 내용 10분 안에 또 올리기 / 한 사람이 1분에 3개 넘게 올리기 → DB 가 거절
- 같은 브라우저 20초 안에 연달아 올리기 → 화면에서 막음
- 사람 눈에 안 보이는 칸(자동 등록기 잡기)
- 글은 글자로만 보여 줌 (HTML·스크립트 실행 안 됨)
